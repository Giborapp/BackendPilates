# Permissions

Initial permissions:

- `dashboard.read`
- `classes.read_own`
- `classes.read_all`
- `classes.create`
- `classes.update`
- `classes.cancel`
- `attendance.read`
- `attendance.manage`
- `students.read`
- `students.create`
- `students.update_basic`
- `students.update_sensitive`
- `students.archive`
- `assessments.read`
- `assessments.create`
- `assessments.update_draft`
- `assessment_templates.manage`
- `trial_students.manage`
- `payments.read`
- `payments.manage`
- `reports.read`
- `staff.manage`
- `permissions.manage`
- `studio_settings.manage`
- `audit_logs.read`
- `devices.manage`
- `capacity.override`

`ADMIN` has all permissions. Other roles receive documented defaults and optional custom permissions.
